# NCSI 2022 v1 Template Manifest

## Sources and fidelity

- Layout and page order: provided NCSI diagnostic report PPTX (104 slides, 10.8333 x 7.5 inches).
- Container structure: Container Map v2 (141 containers).
- Coordinates use a 0-1000 scale on the actual source canvas, origin at top-left; source aspect ratio is 13:9, not 16:9.
- Source slide headings are retained where present. Map IDs remain available as `sourceContainerId`. Sample numeric values are not defaults.

## Data integrity

- NCSI values bind to `NCSI` and `ncsi-source-mean`; quality values bind to `A001`-`A049` and `factor-source-mean`. AI drafts have no numeric field bindings.
- Respondent distributions bind to `GENDER`, `AGE1`, `NATIONAL`, and `B0101`. Unsupported behavior metrics have no numeric binding and show unavailable status.
- Competitor identity resolves from project settings/data.

## Layout and review notes

Container Map placements are normalized to regions on the source canvas. Coarse regions require calibration against rendered source slides before pixel-perfect production export. The schema captures structure and traceability; it does not claim every source visual has been rebuilt.

The source text extraction returned 140 generation-condition entries for 141 containers. The unmapped condition is explicitly marked for consultant review rather than inferred. Container source descriptions and the extracted conditions remain in the template.
